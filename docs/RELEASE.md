# SprintSelect Windows 体验版

适用 Windows 10/11 x64。请在本页面的 **Assets** 中下载：

- `SprintSelect-0.1.0-Portable-x64.exe`：免安装版，双击运行。
- `SprintSelect-0.1.0-Setup-x64.exe`：安装版，可选择安装目录。
- `SHA256SUMS.txt`：上述安装文件的 SHA-256 校验值。

首次建议用 20～50 张照片确认流程，再导入完整赛事。

支持键盘快速保留/淘汰、撤销、评级、模糊提醒、相似照片并排对比、本地数字号码识别、人物标签和拍摄时间检索，以及分组复制导出。原片不会被删除、移动或改写，筛选进度自动保存在本机。

当前限制：人物采用手工标签，尚无自动人脸识别；RAW 需先转换为 JPEG 等支持格式；数字 OCR 为辅助结果，需要人工核对。本版本未进行商业代码签名，不应为运行软件而关闭系统防护。

发布文件由同仓库 GitHub Actions 在 Windows runner 中安装依赖、测试和构建。CI 成功不代表已经在用户的 Windows 实机上完成使用验收。
