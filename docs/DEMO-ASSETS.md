# 示例素材

浏览器演示使用以下公开项目自带的测试/演示照片。它们不是用户照片，示例标签、号码、照片名称与拍摄时间由应用手工设置，不代表图片人物的真实身份或真实 OCR 输出。

- `public/demo/sports-01.jpg`：OpenMMLab MMPose COCO 测试样本 `000000000785.jpg`，https://github.com/open-mmlab/mmpose/blob/main/tests/data/coco/000000000785.jpg
- `public/demo/sports-03.jpg`：OpenMMLab MMPose COCO 测试样本 `000000196141.jpg`，https://github.com/open-mmlab/mmpose/blob/main/tests/data/coco/000000196141.jpg
- `public/demo/football-01.jpg`：Ultralytics 公开示例 `zidane.jpg`，https://github.com/ultralytics/ultralytics/blob/main/ultralytics/assets/zidane.jpg

图片版权与原项目中的相应使用条款归原权利人。产品正式发布前可以直接替换为自行拍摄并授权的赛事照片；运行中的 Windows 客户端默认只打开用户导入的本地照片。
